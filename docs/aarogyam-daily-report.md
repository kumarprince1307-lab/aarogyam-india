### 1.3 वेदर क्वेरी में रॉ JSON लीक की पूर्ण रोकथाम (Zero Raw JSON Leak Shield)
* **समस्या:** मौसम बटन दबाने पर `{"key":"rewa","lat":24.5362,"lon":81.3038...}` जैसा बदसूरत रॉ JSON यूजर के मैसेज बबल और सखी के जवाब में छप रहा था।
* **समाधान:**
  * `handleUserSubmit` और `appendUserMessage` के शीर्ष पर स्वचालित सैनिटाइजर लगाया गया:
    ```javascript
    if (query.includes('{') && query.includes('}')) {
      query = query.replace(/\s*\(\s*\{[^}]*\}\s*\)/g, '').replace(/\{[^}]*\}/g, '').trim();
    }
    ```
  * `window.openSakhiWeatherForecast` को केवल स्वच्छ शहर का नाम (`रीवा`) भेजने हेतु सुरक्षित किया गया।
