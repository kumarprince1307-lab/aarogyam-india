* **समाधान:**

    ```javascript
    if (query.includes('{') && query.includes('}')) {
    ```

* **सेंटर ग्लोइंग अवतार:** सखी खुलते ही स्क्रीन के केंद्र में सखी का 90px अवतार मल्टी-लेयर्ड कॉस्मिक ग्लोइंग रिंग्स (एमराल्ड, क्यान, गोल्ड) के साथ लेविटेट/फ्लोट करता है।
* **वेब ऑडियो चाइम:** बिना किसी बाहरी mp3 फाइल के Web Audio API द्वारा शुद्ध 4-टोन क्रिस्टल चाइम (E5, G#5, B5, E6) बजाया जाता है (0ms लेटेंसी, 100% ऑफलाइन)।
* **हेडर फ्लाइट ट्रांजिशन:** 1.1 सेकंड बाद अवतार केंद्र से उड़कर हेडर के अवतार फ्रेम (`#sakhiAvatarFrame`) में डॉक हो जाता है और हेडर में रिपल ग्लो उत्पन्न होता है।
* **वॉइस ग्रीटिंग:** स्क्रीन पर नमस्ते संदेश आने के साथ सखी आवाज में बोलती है: *"नमस्ते [नाम] जी! मैं आपकी सखी AI हूँ। कोई भी सवाल पूछें या मेनू देखें, मैं सही समाधान दूँगी।"*
* **फास्ट स्किप सपोर्ट:** स्क्रीन पर कहीं भी टैप करते ही एनिमेशन तुरंत स्किप होकर चैट तैयार हो जाती है।

## 🚀 6. एडमिन पैनल सखी AI टैब: 20-20 पेजिनेशन, साइड ड्रॉअर, फल ज्ञानकोष व जेमिनी टोकन ऑडिट (29 अक्टूबर 2026)

### 6.1 एडमिन पैनल सखी टैब: 20-20 रिकॉर्ड पेजिनेशन (20 Items Per Page)

  2. **सखी उपयोगकर्ता संवाद तालिका (`sakhiUsersTableBody`):** प्रति पृष्ठ ठीक 20 रिकॉर्ड।
  3. **टीम स्पॉन्सर AI लीड्स तालिका (`sakhiTeamLeadsTableBody`):** प्रति पृष्ठ ठीक 20 रिकॉर्ड।
  4. **छूटे हुए सवाल तालिका (`sakhiUnansweredTableBody`):** प्रति पृष्ठ ठीक 20 रिकॉर्ड।
* **स्मार्ट पेजिनेशन बार UI (`renderPaginationControls`):**
  - "दिखा रहे हैं 1-20 (कुल N में से) • पृष्ठ X / Y"
  - `[◀ पिछला (Prev)]` बटन
  - सीधे पृष्ठ संख्या बटन `[1] [2] [3] ...`
  - `[अगला (Next) ▶]` बटन
  - बटन क्लिक करने पर पृष्ठ शीर्ष पर स्मूथ स्क्रॉल।
* **डेटाबेस फेच लिमिट अपग्रेड:** सुपाबेस फेच लिमिट 100 से बढ़ाकर 1,000 की गई ताकि पूरा डेटा 50+ पृष्ठों में देखा जा सके।

### 6.2 मोबाइल रिस्पॉन्सिव साइड ड्रॉअर (Sliding Side Drawer Offcanvas)
* मोबाइल व डेस्कटॉप पर टेबल के फैलने व कटने की समस्या को हल करने हेतु **यूनिवर्सल स्लाइडिंग साइड ड्रॉअर (`#sakhiDetailDrawer`)** का निर्माण:
  - किसी भी पंक्ति या `[👁️ विवरण]` बटन पर टैप करते ही ड्रॉअर दाईं तरफ (मोबाइल पर नीचे से) स्मूथली स्लाइड होता है।
  - **ड्रॉअर में उपलब्ध विवरण:**
    - 👤 उपयोगकर्ता का पूरा नाम व 10 अंकों का मोबाइल नंबर
    - 💬 1-क्लिक डायरेक्ट WhatsApp चैट बटन (`wa.me`)
    - 📞 1-क्लिक डायरेक्ट कॉल बटन (`tel:`)
    - 🕒 सटीक दिनांक, समय व डोमेन बैज (कृषि / स्वास्थ्य / पशुपालन)
    - 🚦 ऑडिट स्थिति (PASS / FAIL)
    - ❓ उपयोगकर्ता का पूरा मूल सवाल (Query) + 1-क्लिक कॉपी बटन
    - 🤖 सखी का सम्पूर्ण वैज्ञानिक उत्तर (AI Answer) + 1-क्लिक कॉपी बटन
    - 📚 सुझाई गई डिजिटल ई-बुक / प्रोडक्ट लिंक

### 6.3 लाइव ऑडिट व तालिकाओं में मल्टी-फ़िल्टरिंग

### 6.4 जेमिनी 1.5 फ़्लैश AI मास्टर कंट्रोल सेंटर: टोकन स्पाइक विश्लेषण व स्पष्टीकरण
* **कारण विश्लेषण:** एडमिन के 'जेमिनी 1.5 फ़्लैश AI मास्टर कंट्रोल सेंटर' में दैनिक चार्ट सखी के सभी प्रश्नों (लोकल 0-Egress + एक्सटर्नल) का कुल एक्टिविटी वॉल्यूम फॉर्मूला `(सवाल+जवाब)/2.5` द्वारा सिमुलेटेड टोकन के रूप में दिखा रहा था।
* **सुधार:**
  - बॉक्स 1: **कुल 7-दिवसीय AI टोकन**
  - बॉक्स 2: **आज के फोटो विज़न (API)**
  - बॉक्स 3: **सखी 0-Egress प्रश्न (₹0 फ्री)**
  - स्पष्ट सूचना बैज: सखी के 98%+ प्रश्न स्थानीय सुपर-इंजन (0-Egress) से ₹0 API खर्च पर हल होते हैं। केवल कैमरा/फोटो विज़न ही गूगल जेमिनी API का उपयोग करता है।

### 6.5 सखी फल बागवानी ज्ञानकोष (Fruit Orchards) बहुभाषी विस्तार
* **आम, अनार, केला, पपीता, अमरूद, जामुन** के सम्पूर्ण वैज्ञानिक ज्ञान को बहुभाषी (हिंदी, मराठी, गुजराती, बंगाली, हिंग्लिश, अंग्रेजी) में अपग्रेड किया गया:
  - **आम (Mango / કેરી / आंबा / আম):** दशहरी, लंगड़ा, चौसा, आम्रपाली HDP (2.5x2.5m), बौर सुरक्षा, पाउडरी मिल्ड्यू (रैप-अप 30ml + बायो-99 5ml), बायोफिट 4-स्टेज स्प्रे शेड्यूल।
  - **अनार (Pomegranate / દાડમ / डाळिंब / ডালিম):** भगवा सिंदूरी, बहार प्रबंधन (मृग, हस्त, अम्बे), बैक्टीरियल ब्लाइट तेला (रैप-अप 40ml + बायो-99 5ml), फल फटना रोकथाम।
  - **केला (Banana / કેળા / केळी / কলা):** G-9 टिशू कल्चर, पनामा विल्ट उकठा (VAM + शेत ड्रेंचिंग), सिगाटोका लीफ स्पॉट, प्रो स्टिमरिच घार वजन बूस्टर (30-38 किग्रा घार)।
  - **पपीता (Papaya / પપૈયા / पपई / পেঁপে):** रेड लेडी 786, ताइवान 786 (100% फलन, 50-80 किग्रा/पेड़), रिंग स्पॉट वायरस (PRSV) कीट नियंत्रण (इंटैक्ट + बायो-99) व रैप-अप शील्ड, आर्द्र गलन (Damping off - VAM + शेत ड्रेंचिंग), प्रो स्टिमरिच फल वजन।
  - **अमरूद (Guava / જામફળ / पेरू / পেয়ারা):** VNR बिही जंबो (400-1200 ग्राम फल), इलाहाबाद सफेदा, L-49 सरदार, सघन बागवानी (Meadow Orchard 1000-2000 पेड़/एकड़), मृग बहार प्रूनिंग, अमरूद उकठा रोग (Fusarium Wilt) शेत + VAM + धारा संस्कार उपचार, फल मक्खी रोकथाम।
  - **जामुन (Jamun / જાંબુ / जांभूळ / জাম):** रा-जामुन (CISH J-37 बड़ा फल, छोटा बीज), गोमा प्रियंका, मधुमेह (शुगर) हेतु जम्बोलिन औषधीय महत्व, 70% फूल व फल झड़ना रोकथाम (स्टिमरिच + प्रो स्टिमरिच स्प्रे), तना छेदक उपचार।
  - **मायकोराइजा VAM व धारा संस्कार (अमृत मिट्टी):** फॉस्फोरस अवशोषण, सूखा रोधी जड़ संजाल, और 200L पानी + गुड़ + 1L शेत + 1L N,P,K + Zn + VAM + सूखा गोबर निर्माण विधि।
