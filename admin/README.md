Admin Panel V1 — Folder README

- This folder contains the Phase-1 static skeleton and the planned file organization for the locked Admin Panel V1.

Structure overview (Phase-1)

- admin/dashboard.html                 - Dashboard skeleton
- admin/users.html                     - Users list skeleton
- admin/purchases.html                 - Purchases list skeleton
- admin/downloads.html                 - Download logs skeleton
- admin/reports.html                   - Reports skeleton
- admin/settings.html                  - Admin settings skeleton
- admin/css/                           - Admin-specific CSS
- admin/js/                            - Admin-specific JavaScript modules and components

Notes
- Do not enable or link these pages from public pages until Phase-2 completes server-side admin auth and RLS.
- Files are intentionally static and safe. They include TODO placeholders for Phase-2 work.
